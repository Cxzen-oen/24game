## 4. 更新发布

本地：

~~~powershell
cd D:\24game
powershell -ExecutionPolicy Bypass -File deploy\build-local.ps1
~~~

脚本用独立目录 .build/server 构建，不会和本机 8080 的旧 jar 抢文件；产物在 deploy/build/game24-demo.jar。

上传并重启：

~~~powershell
scp deploy\build\game24-demo.jar root@121.43.236.209:/opt/game24/game24-demo.jar
ssh root@121.43.236.209 "chown game24:game24 /opt/game24/game24-demo.jar && systemctl restart game24"
~~~

验证：

~~~bash
curl -s http://127.0.0.1:8081/api/health
journalctl -u game24 -n 30 --no-pager
~~~

数据库迁移由 Flyway 在启动时自动执行；升级前建议先跑一次 /opt/game24/backup-native.sh。

## 8. 安全与限制

- 当前是 **HTTP**，COOKIE_SECURE=false；refresh cookie 会明文传输，测试期不要用真实重要密码。
- 没有域名，所以没有 HTTPS；正式使用前应：
  1. 域名解析到 121.43.236.209；
  2. 安全组放行 80/443；
  3. 安装 Caddy（或 Nginx + certbot）反向代理到 127.0.0.1:8081；
  4. 把 /opt/game24/game24.env 的 COOKIE_SECURE 改为 true 并重启。
- 数据库只监听本机，公网不可达；JWT/数据库密码在 600 权限的 env 文件里。
- 没有防作弊判定；榜单只适合小范围可信测试。
