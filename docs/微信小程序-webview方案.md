# 微信小程序 web-view 方案（B 方案）

> 适用：学校/学院等非个人主体，已有或即将有公众号，想把现有 H5 快速装进小程序，在文章里一键进入。
> 不适用：个人主体、小游戏账号、没有备案域名、希望两周内上线。

## 1. 方案长什么样

~~~text
公众号文章
   │ 插入「小程序卡片」（需公众号与小程序关联）
   ▼
微信小程序（原生壳）
   ├─ 首页：活动说明、规则、排行榜入口、我的成绩
   ├─ 玩法页：web-view 加载现有 H5
   └─ 关于/隐私：原生页面
        │ HTTPS
        ▼
现有 H5 + Spring Boot API + PostgreSQL
~~~

核心：**小程序只做壳和入口，游戏仍是现在的 H5**，所以不用重写对局、判题、排行榜。

## 2. 先确认 4 个硬条件

| 条件 | 要求 |
|---|---|
| 主体 | 学校/学院/企业等**非个人主体**；个人主体不能用 web-view |
| 小程序 | 已注册、已认证更稳；类目选工具/教育，不要选游戏 |
| 域名 | 已 ICP 备案、HTTPS、无端口；配置到「业务域名」 |
| 公众号 | 文章要插小程序卡片，需公众号与小程序关联；没有公众号就只能放小程序码/二维码 |

## 3. 必做步骤

### 3.1 主体与账号

- 注册小程序，拿到 AppID；
- 完成微信认证（学校主体一般可用事业单位法人证书）；
- 小程序名称、简介按“数学练习/益智工具”写，避开“游戏、对战、竞技”；
- 类目选工具或教育，具体以后台可选为准。

### 3.2 域名与 HTTPS

- 域名 ICP 备案（7～20 个工作日，最耗时，先启动）；
- 配 HTTPS 证书（Caddy 自动签发即可）；
- 小程序后台「开发管理 → 开发设置」：
  - request 合法域名：填 API 域名；
  - 业务域名：填 H5 页面域名，并上传微信校验文件到域名根目录。

### 3.3 小程序壳

不要只放一个全屏 web-view，容易被判“无实质内容”。建议原生页：

1. 首页：活动介绍、规则、开始游戏、排行榜、我的成绩；
2. 玩法页：web-view 指向 H5（可带登录票据）；
3. 排行榜：可以直接原生调 API，也可以 web-view；
4. 我的/关于/隐私政策。

### 3.4 登录桥（关键）

web-view 里的 H5 **不能直接调用 wx.login**。两种做法：

**做法 A：不打通微信身份（最省事）**

- 小程序直接打开 H5，用户在 H5 里以游客玩，或手动注册/登录；
- 排行榜只统计注册用户；
- 适合“先玩起来”，但“点进去自动上榜”体验差。

**做法 B：一次性票据（推荐）**

~~~text
小程序 wx.login() → code
        │
        ▼
后端 jscode2session → openid → 找到/创建账号 → 生成一次性 ticket（60 秒）
        │
        ▼
web-view URL: https://game.example.com/#ticket=xxxx
        │
        ▼
H5 读取 hash 里的 ticket → POST /api/auth/wechat/exchange
        │
        ▼
返回 accessToken + refreshToken（JSON）→ H5 存起来 → 清掉 URL 里的 ticket
~~~

后端要加：

- account_identities（provider=WECHAT, subject=openid）；
- /api/auth/wechat/login（code 换 openid + 建号/登录）；
- /api/auth/wechat/ticket（生成一次性票据）；
- /api/auth/wechat/exchange（票据换令牌，票据只能用一次、绑定 openid）；
- refresh 支持 X-Refresh-Token 头（web-view 里 Cookie 不如 Header 稳）。

这样用户从文章点进来，不需要输账号密码，直接是同一个微信身份，成绩和排行榜连续。

### 3.5 文章入口

- 公众号与小程序关联后，在文章编辑器插入「小程序卡片」或「小程序文字链接」；
- 没有关联，就放小程序码/二维码，读者长按识别；
- 文章里不要写“点击外链”，微信正文不支持普通外链，只能“阅读原文”。

## 4. 审核风险与规避

| 风险 | 规避 |
|---|---|
| 纯 web-view 被判“无实质内容” | 加原生首页、规则、排行榜、关于页；web-view 只承载玩法 |
| 类目不符/被判游戏 | 定位“数学心算练习”，不写游戏、不做虚拟支付/抽奖/对战下注 |
| 业务域名校验失败 | 域名已备案、HTTPS、校验文件可访问、管理员扫码 |
| 登录/隐私问题 | 小程序后台填隐私保护指引；H5 也提供隐私政策 |
| 分享受限 | 用小程序 onShareAppMessage，分享卡片带活动参数 |

## 5. 时间线（顺利情况）

| 步骤 | 时间 |
|---|---|
| 小程序注册/认证 | 1～3 个工作日 |
| 域名 ICP 备案 | 7～20 个工作日 |
| 小程序备案 | 平台 1～2 天 + 管局 1～20 个工作日 |
| 壳 + 业务域名 + web-view | 2～3 天 |
| 登录桥后端 + H5 改造 | 2～3 天 |
| 提审到上线 | 1～7 天 |
| **合计** | **约 3～5 周**（备案与开发并行） |

如果活动两周内就要开始，B 方案赶不上，先用 H5 + 阅读原文/二维码。

## 6. 代码改动清单

### 后端

- [ ] account_identities 表（V3 迁移）
- [ ] WeChatClient：jscode2session、access_token 缓存
- [ ] /api/auth/wechat/login
- [ ] /api/auth/wechat/ticket + /exchange
- [ ] refresh/logout 支持 X-Refresh-Token
- [ ] WECHAT_APP_ID / WECHAT_SECRET 环境变量

### H5

- [ ] 读取 URL hash 里的 ticket，调用 exchange，存 token，清 URL
- [ ] 请求头带 Bearer；401 用 refresh 重试
- [ ] 无 ticket 时保持现有游客/账号登录
- [ ] 隐私政策页

### 小程序

- [ ] 原生首页/排行榜/关于
- [ ] 玩法页 web-view，拼接 ticket
- [ ] 业务域名、request 域名
- [ ] 分享、隐私弹窗

## 7. 如果审核被拒，怎么退

1. 先按驳回原因补原生页面/类目说明；
2. 仍被判“游戏”，改走小游戏（IAA 备案/版号）或退回 H5；
3. H5 永远保留：文章“阅读原文”、二维码、学校官网链接都能用，不依赖小程序审核。

## 8. 一句话建议

**学校非个人主体 + 有备案域名 + 能等 3～5 周，B 方案是“文章一键进入 + 不重写游戏”的最优解；如果活动很急，先用 H5，不要为了小程序卡审核。**
